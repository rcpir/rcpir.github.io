    Read Wikipedia privately

    Lead sections of the most-read English Wikipedia articles. Each lookup is answered by two servers using RC-PIR, so neither the website host nor the compute server learns which article you opened.

    1. The title list is downloaded once; search runs in your browser.
    2. Opening an article fetches s random-looking blocks from the website host and sends one scrambled query to the compute server.
    3. Your browser combines the answers into the article. Every lookup looks the same on the network.
