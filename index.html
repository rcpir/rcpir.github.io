    Read Wikipedia without revealing what you read

    This site is a working implementation of Retrieve-Compute PIR (RC-PIR), from Retrieve-Compute PIR and Its Applications by Benny Applebaum and Shahar Shechter (ePrint 2026/1372). It holds the lead sections of the … most-read English Wikipedia articles, a … database X.

    How RC-PIR works

    • Once, offline: X is encoded with a public random matrix H into R = X·H (…). R is public and hosted on GitHub Pages, a retrieval-only server that just serves files and computes nothing.
    • To read article i, your browser picks … blocks of R uniformly at random, independently of i, and downloads them from GitHub Pages.
    • From the same random choice, it builds the query q = H·e + ei (e marks the … blocks) and sends it to the compute server, which returns X·q.
    • Your browser removes the retrieved blocks: X·q − Σj Rj = X·ei, the block holding your article. That's about … per lookup.

    Why neither server learns what you read

    GitHub sees … uniformly random blocks, the same distribution whatever the article. The compute server sees q, which under the Learning Parity with Noise (LPN) assumption is indistinguishable from random. Privacy could only break if the two views were combined. GitHub Pages provides no access logs to site owners, so as long as GitHub doesn't collaborate with the operator of the compute server (the author of this demo), the compute server learns nothing about your query.

    Search runs in your browser on a title list downloaded once; nothing you type is sent anywhere.
